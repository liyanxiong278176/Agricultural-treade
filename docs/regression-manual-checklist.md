# 设备人工回归清单

自动化不能代替下列目标设备检查。涉及相应行为的改进后，应执行对应项目；未接入设备时填写“未验证”，并记录限制，不得填写通过。

| 项目 | 操作及预期 | 本轮状态 |
| --- | --- | --- |
| 安卓触屏操作 | 登录；选择工人、产品、班组、地块；斤/公斤直接录入；选择毛重/单筐重配置及容器数、查看只读净重；连续录入；更正归属；查询分页；登记付款；删除确认；导航与退出，键盘和按钮可正常使用 | 未验证：未接入安卓实机 |
| 设备 HTTPS 信任 | 按 README 在目标设备安装演示 CA，以正确局域网地址打开 HTTPS，无证书警告；Service Worker 正常控制页面 | 未验证：未接入目标设备 |
| 实机离线重开 | 联网准备后断开网络，保存记录并关闭页面；重开仍能看到本机操作；恢复网络后只入账一次，金额及实际作业日期正确 | 未验证：未接入安卓实机 |
| 实机账号隔离 | 原账号离线保存后退出并切换账号，待传内容不混入新账号；切回原账号仍保留 | 未验证：未接入安卓实机 |
| 实体打印 | 打印每日核对表，核对纸张方向、分页、表头、签字栏、数值和工人完整性；更正后查看旧快照差异，再生成新版打印 | 未验证：未连接实体打印机 |

执行时另记日期、操作者、设备/浏览器/打印机型号、软件版本、所用隔离环境、结果及证据路径。自动化已覆盖的手机宽度、离线网页缓存与 PDF 输出仍单独报告。
