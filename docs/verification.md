## 真实 MySQL 测试命令

先启动本地演示 MySQL，再在 backend 目录执行：

```powershell
$env:JAVA_HOME='D:\jdk21\jdk-21.0.10'
$env:TEST_DB_URL='jdbc:mysql://127.0.0.1:13316/harvest_test?createDatabaseIfNotExist=true&serverTimezone=Asia/Shanghai'
$env:TEST_DB_USER='root'
& 'D:\apache-maven-3.9.12\bin\mvn.cmd' test
```

测试会清理专用 `harvest_test` 中的业务表。代码只允许测试库名 `farm`（H2）或 `harvest_test`，不能把测试连接指向业务库。
