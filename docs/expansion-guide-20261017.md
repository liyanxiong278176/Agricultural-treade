# 功能扩展使用说明

## 每日派工

电脑侧栏或手机左上角导航进入“每日派工”。选择日期，新增工人、上午/下午、班组、产品、地块安排。同一工人同一时段允许多项安排。

实际采摘无需先有派工。匹配的实际采摘量上传后，名单显示“已有记录”；这不代表数量已全部录完。临时换组、换产品或换棚，点击“调整 / 说明”，选择“临时变更”，注明实际去向和原因；原安排保留。请假、未出工或取消安排选择“未作业说明”。说明与后续实际记录不符时会提示重新核对。

已完成离线准备的设备可以断网查看下载的名单、修改派工并保存。待同步操作在本页单列，联网自动补传；冲突会显示最新安排，核对输入后重提。提交结果未知时不能舍弃或改写原操作，先重连确认；退出后原账号重新登录仍可处理。

## 地块、大棚及人工成本

老板在“基础资料 → 地块 / 大棚”建立资料；老板与记录员也可通过批量导入建立地块。

采摘录入或增加数量时同时选择实际班组和地块。原时段记录仍只有一条，各班组和地块数量组成原总量。允许暂选“未指定地块”，之后核实补齐。

“更正数量”修改所选班组、所选地块的正确累计量，不影响其他组成。“更正地块”把该班组原地块的数量移至正确地块，保持总量和工资不变。填写原因并保留修改经过。仅改地块不要求重新签字，改数量或工资需重新核对签字。

记录员可更正本人和其他记录员录入的往日、已结算记录。已确认结算账单不被改写，差额仍由老板在“月度工资”确认补结算；记录员没有结算和付款权限。已结算记录仍不能直接删除。

进入“地块人工成本”，按账本月份查看各棚、各产品数量与人工成本。纯计重按净重分，纯计件按筐数分；分段混合按各阶段分摊；自动分配模式先对总重量计薪，再按各棚净重分摊。金额分配到分，合计与原工资一致。当前成本不等于已结算或已支付，不包含农资等其他经营成本。

历史没有地块的数量保留在“未指定地块”，不自动推测地点。公斤和筐不混加；只有适合的同类数量才显示单位人工成本。

## 资料批量导入

老板和记录员均可进入“资料批量导入”，支持工人、班组、产品类别、产品、地块/大棚和筐型。

1. 选择资料类型，点击“下载已有资料及模板”。
2. 更新已有资料时保留原行编号，仅修改需要更新的格子；新增资料填写新行，编号留空。新增工人的工号必填。
3. 上传文件，点击“预览并校验”。检查原资料、待保存资料、跳过及关联创建。
4. 全部行无错误后，点击“确认整批导入”。保存失败时整批撤销，不保留半批结果。

工人只新增，已有工号跳过，不能通过换工号更新已有编号。其余资料可经确认更新。可选空白保留原值；名称、产品类别、筐型重量等必填项为空仍报错。缺失的关联班组或类别会在预览中明确列出，确认后一起创建。更新筐型不重写旧记录的皮重快照。

每批最多1000行、3MB，使用系统模板，不支持公式。批次内重复识别信息应先修正。预览后后台资料改变会要求重新预览，不覆盖他人刚修改的内容。新建产品不会自动发布计费规则，需老板单独配置。

## 打印快照与旧表对比

“每日核对”选择日期、班组和签字状态，点击“打印核对表”。系统刷新后台账目，保存本次内容、版式、生成时间、操作人及版本，然后打印该版本。浏览器取消打印，版本仍留存。

页面下方“历史打印快照”可查看旧版原表及与当前账目的差异、相关修改人和原因。旧版不会跟随数量、价格或模板修改而变化，仅用于查看和对比，不提供旧版重打。再次打印一律使用当前账目并保存新版本。

老板和记录员均可核对往日完整日账，收回工人实际签字纸表后再点击“登记已签字”。生成快照不代表纸张实际打印、工人已签字或已领工资。

批量导入、每日核对、历史快照查询与对比、打印及签字登记需要联网；本机当天有未处理采摘操作时，先同步核对。系统不能证明其他长期离线设备已经全部上传。
