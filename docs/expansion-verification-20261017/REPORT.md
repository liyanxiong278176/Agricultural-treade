## 主要业务证明

- 同一时段两个棚的数量仍汇总到一条采摘记录；班组汇总保持一致，工资不重复计算。
- 纯计重、纯计件、分段混合及总重量分配采用确认的成本归属规则。分币尾差稳定分配，合计不多算或少算。
- 记录员可更正他人旧记录和已结算记录，原因必填，版本校验仍生效，原结算快照不变，工资差额进入待补结算。结算、付款、规则发布等老板专属权限保留，已结算删除仍被拒绝。
- 仅移动地块保留原数量输入、单位和班组汇总，不使纸表签字失效；包括旧版斤录入记录。数量更正使签字需重新核对。
- 派工不产生采摘记录或工资；离线保存、联网上传沿用同一操作编号。并发冲突保留原输入与后台最新安排。未作业说明和实际记录矛盾时提示核对。
- Excel 预览不写业务资料；记录员可确认导入并创建缺失的关联班组。已有工号跳过，不修改工人；无效行阻止整批，提交时后台发生变化则整批回滚。
- 打印快照保留原内容及版式；更正后旧版不改变。对照显示原值、现值和相关修改人、时间、原因；同一工人的打印后补录也纳入对照。历史快照没有旧版重打入口。
- 较早发出的页面刷新不能覆盖刚提交的新版本；旧回执补传也不覆盖本机已确认的较新版本。
