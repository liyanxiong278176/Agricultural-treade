# 地块扩展保留时段唯一记录与统一计薪

为支持同一工人同一时段跨班组、跨地块采摘，用户确认保留“工人、实际日期、上午/下午、产品”唯一的原采摘记录，在记录内保存班组与地块共同归属的数量组成，而不按地块拆成新的同级采摘记录。工人工资仍对原记录统一核算，地块成本再按已确认的计费方式分摊，避免改变原有计费条件、半筐折算、舍入及结算边界。

派工安排是计划，可以多项并存；数量组成是实际工作量归属，不是独立交筐记录或额外计薪记录。即使界面按地块展示多行，也不能将各行重新独立计算并累加为新的应发工资。

依据：2026-10-17 访谈决策 8–13，详见 discovery.md；成本分摊尾差细则仍待确认，不在此 ADR 中预先批准。
